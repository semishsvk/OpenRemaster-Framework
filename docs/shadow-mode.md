# Shadow mode

The Change Impact Analyzer is advisory only.

It may:
- observe project revisions,
- consume copied/exported evidence,
- calculate invalidation sets,
- emit plans into the framework workspace.

It may not:
- modify OpenAzrael or OpenCadaver,
- suppress authoritative tests,
- change project branches or refs,
- merge or commit into project repositories,
- promote its own result to a release gate.

The checked-in baseline observations are point-in-time evidence, not moving aliases. A later observation must create a new SHA-bound result rather than rewriting history.
